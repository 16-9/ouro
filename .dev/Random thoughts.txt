1. Metaclass (The Prime Candidates)
Most of the bloat in the system is currently sitting on the Metaclass prototype. The core loader only needs to wire prototypes and stash the definition; it does not need to answer questions about the system state.

getSubclasses (Prototype): The core engine doesn't care who inherits from a class once the prototype chain is wired. This is pure Introspection.

getInstances (Prototype): Tracking active instances is a memory-heavy policy decision. This belongs in a Tracking/Introspection extension.

getBlueprint (Prototype): This is your serialization/stringifier tool. The engine never needs to read its own blueprint to run. This belongs in a Serialization extension.

getName & getParent (Prototype): If the rewritten core accesses the raw __private.class.definition directly during setup, these public getters are strictly for developer reflection and can be moved to Introspection.

toString (Constructor): Custom stringification for the class object itself is pure developer DevTools sugar.

2. Method
The core dispatcher only needs to evaluate applicability and execute the body. It does not need public-facing reflection APIs.

getSpecializers (Prototype): Pure Introspection. The internal engine can read the specializers property directly during dispatch.

getQualifier (Prototype): Pure Introspection.

getBody (Prototype): Pure Introspection.

toString (Constructor): DevTools serialization sugar.

3. GenericFunction
Similar to Method, the generic dispatcher just needs to route arguments to the right method body.

getMethods (Prototype): Returning the array of bound methods is a reflection query used by developers to see what a generic function can do. Pure Introspection.

getName (Prototype): Pure Introspection.

toString (Constructor): DevTools serialization sugar.

 * Declarative schema: / structure: on Page (Page.prototype.scrape): Pages can declare schema: { ... } and namespace: "..." in their class definition; Page.prototype.scrape() automatically instantiates JSONExtractor or DOMExtractor, populates this.scraps and this.data, and wraps this.data[namespace] without needing a custom scrape() method.
 * Declarative DOM Factory & Fluent Helpers on DOMValue (DOMValue.create, .attr, .on, .append / .appendTo): Build and wire DOM elements fluidly using the same DOMValue wrapper used for scraped elements.
 * Network Concurrency Limiter & Automatic Retry (Page._networkFetch): Limits concurrent in-flight fetches (Page.maxConcurrent = 8) and automatically retries transient network failures or HTTP 429/502/503/504 responses.
